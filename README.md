# Game dev — a jobslop plugin

Work With Indies job board and game studios on the map (Game Dev Map and Wikipedia's indie developers), plus your games portfolio in the profile.

## What it adds

- **Job boards:** WorkWithIndies (Indie games studio jobs worldwide)
- **Profile fields** (the Chrome extension fills them in on application forms): Games portfolio / itch.io page, Engines (Unity, Unreal, Godot…), Shipped titles
- **On screen:** see `ui.js` (tabs, map layers or Progress cards)
- **Its own words in:** da, es, nl

## Install

It comes with jobslop — switch it on in **Settings → Plugins**.

To get a newer version before jobslop's next release: **Settings → Plugins → Check for plugin updates**,
or paste `https://github.com/JobSlop/jobslop-plugin-gamedev` into **Install from link**.

## Making changes

See the plugin guide, `docs/PLUGINS.md` in the [jobslop repository](https://github.com/JobSlop/jobslop).
Raise `version` in `plugin.json` and publish a GitHub release tagged `v<version>`.
